증상확인할 것
커넥터 추가 시 연결 실패주소가 https://로 시작하고 끝에 /mcp가 붙어 있는지
대화에서 도구를 쓰지 않음입력창 + → 커넥터에서 이 도구가 켜져 있는지
429 / 요청이 너무 많음짧은 시간에 요청이 몰려 잠시 제한됐습니다. 1분쯤 뒤 다시 시도
특허 검색 결과가 안 나옴키 없이 쓰는 Google Patents 검색은 접속이 몰리면 잠시 제한될 수 있습니다. 잠시 뒤 다시 하거나 특허 검색과 KIPRIS 키의 다른 방법을 쓰세요
데스크톱 앱에 안 보임같은 계정으로 로그인했는지 확인하고 앱을 완전히 종료했다가 다시 열기

🔎 특허 검색과 KIPRIS 키

인증키 없이도 Google Patents로 한국 특허를 키워드·출원인으로 검색합니다. 다만 비공식 경로라 권리 상태가 없고 접속이 몰리면 잠시 제한될 수 있습니다. 공식 KIPRIS 검색과 출원번호 조회는 KIPRIS Plus 인증키가 있을 때 됩니다 — 사용자 각자의 키를 쓰는 방식이라 한 사람의 사용량이 다른 사람에게 영향을 주지 않습니다.

키 없이도 되는 것

  1. 키워드·출원인 검색 (Google Patents, 예: “농촌진흥청 떡 제조 특허 찾아 줘”)
  2. 등록번호·공개번호로 특허 조회 (예: “10-1070281 특허 요약해 줘”)
  3. 권리 상태·존속기간·연차료 확인
  4. 공보 원문을 붙여 넣어 분석·요약·권리범위 대조
  5. 국유특허 업무 도구 전부 (보상·처분·실시료·수탁기관 등)

KIPRIS 웹에서 찾아 넘기기

Google 검색이 제한되거나 출원번호만 알 때

  1. KIPRIS(로그인 없이 무료)에서 키워드·출원인으로 검색
  2. 찾은 특허의 등록번호나 공개번호를 Claude에 알려 주거나
  3. 공보 전문을 복사해 붙여 넣고 “이 공보 분석해 줘”

내 인증키로 공식 검색

  1. KIPRIS Plus → 데이터 신청 → Open API 특허·실용신안 정보검색 신청 후 인증키 발급
  2. 커넥터를 추가할 때 요청 헤더(Request headers)에 이름 x-api-key, 값에 인증키만 입력 (Bearer 붙이지 않음)
  3. 이미 추가했다면 커넥터를 삭제하고 다시 추가 (인증 설정은 나중에 바꿀 수 없음)
🔒 내 인증키는 Claude 계정의 커넥터 설정에만 저장되고, 요청할 때마다 이 서버로 전달되어 그 요청에만 쓰입니다. 서버는 키를 저장하거나 기록하지 않으며 다른 사용자의 요청에 쓰지 않습니다. 키를 대화창에 붙여 넣지는 마세요. 요청 헤더 항목은 베타 기능이라 계정에 따라 보이지 않을 수 있습니다 — 그때는 위 1·2번 방법을 쓰세요.
운영자: 서버 KIPRIS 키는 넣지 않는 것을 권합니다
서버 환경변수 KIPRIS_API_KEY에 키를 넣으면 공개 운영에서 모든 사용자가 그 키 하나의 호출 한도를 나눠 쓰게 되어 금방 막힐 수 있습니다. 서버에는 키를 두지 않고, 검색은 Google Patents로, 공식 검색이 필요한 사용자는 커넥터 요청 헤더로 본인 키를 쓰게 하는 것이 기본 구성입니다. 사용자가 헤더로 키를 보내면 그 요청에는 사용자 키가 우선합니다.
